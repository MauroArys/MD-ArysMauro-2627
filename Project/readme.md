# Placeholder
Plaats in deze map jouw project.

Maak regelmatig commits. Begin hier tijdig aan!

Zodra de opgave van het project is vrijgegeven, kan je al beginnen aan je Layouts (``Composable``s), 
voordat je start aan de navigatie, ``ViewModel``s en het ophalen van de data met Retrofit.

Test je Composables met ``@Preview``s. Dat helpt je om sneller een idee te hebben van wat je aan het maken bent.

**TIPS** : 
* Maak voor je aan de code begint eerst een aantal schetsen zodat je een idee hebt van wat je op welke schermen kan verwachten.
* Maak op tijd je theme aan zodat je het consistent kan gebruiken in je Composables.
* Zorg dat je je eigen code kent, begrijpt en kan uitleggen. Ook wanneer er misschien wat onverwachte code over jouw vragen zouden komen. Als je zelf je code hebt geschreven, kan je altijd wel op die vragen antwoorden.
